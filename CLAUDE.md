# Project Guidelines

## Project Overview

This a dev project that keeps a track of the problems that I've solved in AlgoExpert.

### Tech Stack

- Java and Javascript. Probably Ruby in the future

## Domain Rules

- This is a repo where I'll store the solutions
- Sometimes a solution can have multiple answers.
  - Merge them into one file and have both solution living there
    - Append Vn to the function name. Where n is the number of the current solution
    - Rebuild export to export solutions with the new name
    - Remove extra or outdates exports
  - There might be cases where I could have a recursive or dynamic programming approach
- The exercises are sourced by [Data Structure Questions - Algo Expert](https://www.algoexpert.io/questions)
